Multi-Carrier Transit Network Overview

Atlanta's public transportation network spans five major carriers serving the metropolitan region, representing one of the most comprehensive transit systems in the southeastern United States.

Transit Carriers Analyzed
MARTA - 6,651 stations CobbLinc - 538 stations Ride Gwinnett - 781 stations Xpress - 94 stations Connect Douglas - 47 stations
Critical Connectivity Challenge

Our analysis reveals a fundamental infrastructure issue: only 15 shared stops exist between all carriers out of over 8,000 total stations. This creates significant "bridging gaps" that riders must navigate themselves, typically ranging from 0.22 to 7.7 miles between transit carriers.

This connectivity gap represents one of the primary barriers to increased ridership and system efficiency across the Atlanta metropolitan region.

Network Composition
  • • Largest Component: MARTA (6,651 stations)
  • • Second Largest: Mixed component (CobbLinc, Xpress, Gwinnett: 1,413 stations)
  • • Smallest: Connect Douglas (47 stations)
Shared Transfer Points

Key locations include Civic Center Station, North Avenue Station, and Peachtree Street corridor stops that enable cross-carrier transfers.

Network Science Interpretation

The extremely low density (0.000123) reflects geographic constraints inherent in real-world transit systems, where stops connect primarily to adjacent stops along predefined routes rather than forming theoretical complete graphs.

Positive assortativity across all directional measures confirms a hierarchical "hub-and-spoke" topology where major transfer stations (like MARTA rail stations) serve as regional connectivity nodes.

Network Vulnerability & Attack Simulation Results

Attack Simulation Results

Critical Finding: Network demonstrates high vulnerability to degree centrality attacks (fc = 0.128) but strong resilience to closeness centrality attacks (fc = 0.99). This indicates targeted removal of high-degree nodes rapidly fragments the system.

Attack simulation curves showing network fragmentation under different targeting strategies

Systematic removal of highest-degree nodes (major hubs) rapidly fragments network.

Network maintains connectivity even when nodes with high closeness centrality are removed.

Model Interpretation
Feature Importance:
  • • Neighbor Union (0.75): Total unique neighbors strongly predicts connections
  • • Common Neighbors (0.55): Shared connections indicate potential links
  • • Geographic Distance (-0.036): Slight preference for closer connections
Unexpected Finding:

Preferential Attachment shows negative coefficient (-0.098), suggesting high-degree nodes don't necessarily attract more connections in this transit context.

Transit Applications:

Focus on top 1% of predictions for realistic route planning and cross-carrier connectivity improvements.

Positive Predictors (Pro-Connection):
  • • Neighbor Union: Stops with many total connections likely to link
  • • Adamic-Adar Index: Weighted common neighbors predict new routes
  • • Common Neighbors: Shared intermediate stops suggest direct connections
  • • Jaccard Similarity: Proportional neighbor overlap indicates compatibility
Negative Predictors (Anti-Connection):
  • • Preferential Attachment: High-degree hubs don't automatically connect
  • • Geographic Distance: Physical separation reduces connection probability
  • • Transit Constraints: Real-world routing limitations override theoretical preferences

Transit Planning Tool Development

Dijkstra-Based Routing Tool

Our team developed a transit routing tool that addresses the "First & Last Mile" problem using network science principles:

  • Node Representation: Transit stations (not road intersections)
  • Edge Weights: Travel time or distance between connected stops
  • Optimization: Minimizes expected travel time or distance
  • Input: Start and target locations with user preferences
  • Output: Plotted route with transfer points and fare costs
Current Limitations & Future Development

Tool limitations identified during development:

  • Cross-Carrier Transfers: Limited handling of disconnected carrier networks
  • Bridging Gaps: Users must manually navigate between carriers
  • Data Currency: Analysis based on 3-year-old data
  • Route Changes: Recent service modifications not reflected

Future Enhancement: Implement bidirectional Dijkstra's algorithm and automatic bridging optimization for cross-carrier transfers.

Tool Innovation & Methodology

Unlike commercial routing applications that use complex road network algorithms, our tool focuses specifically on transit network connectivity using:

Network Simplification:
  • • Nearest station identification
  • • Cartesian product of top N closest stations
  • • Reduced search space for efficiency
Dual Network Approach:
  • • Distance-weighted network (haversine)
  • • Time-weighted network (schedule data)
  • • User preference selection
Geographic Integration:
  • • Geocoding API integration
  • • Real coordinate mapping
  • • Visual route presentation
